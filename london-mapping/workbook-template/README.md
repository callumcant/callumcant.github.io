# Workbook template

`London_Project_Mapping_template.xlsx` is generated by `build_workbook.py` —
regenerate it with:

```
python3 build_workbook.py
```

It contains the Excel Tables the app reads/writes via Microsoft Graph (see
`../js/data/table-schemas.js` for the column order each table must keep in
sync with), pre-filled with a couple of clearly-fake `EXAMPLE` rows to show
the expected format. Delete the example rows before pasting in real data —
see `../SETUP.md` for the full upload/connect walkthrough.

This template is deliberately formula-free: the workbook's old computed
tabs (School-level, MAT-level, Branch-level, Project dashboard) are dropped
entirely, since the app computes those rollups itself from the raw tables
(`js/data/rollups.js`) rather than relying on the original file's
Google-Sheets-only array formulas, which don't survive being opened as a
plain Excel file on OneDrive.
